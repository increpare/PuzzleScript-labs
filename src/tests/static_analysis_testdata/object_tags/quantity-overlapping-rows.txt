title Static Analysis Object Tag Quantity Overlapping Rows

(Cells in different rows of one rule can match the same board cell. The
 engine matches every row first, then replaces row by row, so a later row
 sees an earlier row's changes.
 Player: rows 1 and 2 share the player's cell; row 1 clears it, row 2 puts
 it back, row 3 adds one more -> the count can rise.
 Gem: rows 3 and 4 can share one empty cell, so two gems become one -> the
 count can fall.
 Crate: a crate cell and a no-crate cell can never coincide -> a plain move,
 count preserved.
 Hero: as Player, through two concrete HeroA rows -> the group count can rise.
 Knight: each member alone looks safe, but row 2's Knight cell can be row
 1's KnightA cell: row 1 empties it, row 2 refills it with KnightB, and row 3
 adds a KnightA -> the group count can rise.)
