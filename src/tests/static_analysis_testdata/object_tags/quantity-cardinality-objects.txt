title Static Analysis Object Tag Quantity Cardinality Objects

(Player: one per level, only relocates -> exactly one.
 Crate: count preserved, but two in a level -> neither.
 Key: one per level, may be destroyed -> at most one.
 Gem: one in the first level, none in the second, preserved -> at most one.
 Coin: one per level, may be created -> neither.
 Ghost: in no level and never created -> exactly zero (so at most one).
 Bomb: in no level, but may be created -> neither.)
