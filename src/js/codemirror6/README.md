# CodeMirror 6 source ownership

This directory deliberately separates three kinds of code:

- `plugins/` is PuzzleScript-owned editor integration. Edit these files normally
  and refresh `src/editor.html`; no CodeMirror build is required.
- `runtime/source/` is the rarely changed export boundary around the pinned npm
  packages. After changing it or a CodeMirror/Lezer dependency, run
  `npm run build:codemirror` and commit the generated runtime and map.
- `runtime/dist/` is generated output. Do not edit either generated file by hand.

`npm run check:codemirror` verifies the generated bytes without rewriting them.
The release compiler checks those bytes, then concatenates/minifies the runtime,
plugins, and application scripts into its one editor payload.

PuzzleScript's `codeMirrorFn` remains the sole language parser. The plugins use
CM6 `StreamLanguage`; they do not contain a Lezer grammar or a second parser.
