## Behavior dispositions

- Checkpoint restart/load skips `run_rules_on_level_start`: checkpoints already
  contain initialized boards. Fresh restarts still rerun initialization.
  `SessionState.restartTargetIsCheckpoint` replaces the former historical-use
  flag, and `CreateSessionOptions.checkpoint` accepts a saved board snapshot.
- Interactive message/restart commands retain their queue until dismissal;
  restart takes precedence over win. Unsuppressed message wins survive until
  dismissal; initialization/suppressed wins expire at their own turn boundary.
- AGAIN lookahead preserves the current command queue as well as its message.
  It also runs on the board behind a temporary message. Prepared calculation
  caching, explicit random streams and historical probe-effect options remain.
- Sound diagnostics explain missing entities and verbs, while accepted sound
  records retain the typed source-syntax path.
- Closing synonym-cycle links are rejected at registration. Existing final
  normalization already deletes promoted aggregate synonyms correctly, so that
  upstream fix needed no production algorithm change.
- Prototype names are ordinary declarations; the inherited-name compatibility
  shim is removed. Existing Maps already protect object/property/aggregate and
  palette lookup. Prototype object names and invalid palette names have direct
  regressions.
- Only actual rule-direction selectors expand header families. Movement-only
  names now report invalid headers and recover to orthogonal directions.
  Existing InPlace execution-domain regressions remain, with explicit native
  Rule construction at the lower-level test boundary.
- A quiet 200th group pass no longer reports the iteration limit. Nonsettling
  groups still diagnose after the rejected 201st pass.
- Native tagged diagnostic messages stringify only at independent test
  observation boundaries. Source-owned links escape interpolated names;
  ordinary diagnostic text remains text for the rendering host to escape.
  Added native loop debug fields remain allowed by explicit schema guards.

No bit packing, generated matching, native compiler calls or oracle imports were
added to production. The recent inference, error-payload, scanner and accepted
registration boundaries remain intact.
